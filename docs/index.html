About Ultragic

Ultragic is an experimental programming language built on Lua by Kazi Muhtadiul Huda (Rafi).

⚠️ Status: In Development

This project is in its infdev/theory phase. Syntax and features are subject to change. Not production-ready yet.

Ultragic combines powerful language design concepts with innovative mechanics to create a unique programming experience. Whether you're interested in language design, scripting, or experimental features, Ultragic offers something fresh.

Key Features

🔍 Scope System

Advanced scope management with modifiers (g, l, r) for precise variable control across nested scopes.

⚡ LCAF Mechanics

Logic Continuous Auto-Fire system that monitors variables and automatically triggers actions based on state changes.

🎯 CAP Assignment

Conditional Assignment Protocol that evaluates conditions during assignment for powerful conditional logic.

❓ Ask System

Interactive input system with conditional branching for user interactions and game logic.

📍 Tailing Syntax

Innovative tailing syntax for concise and expressive code patterns.

🎮 Event-Driven

Built-in support for event handlers and continuous monitoring with when and on keywords.
